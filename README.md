# Sina Fathi — Academic Website

A modern, minimal academic website for Sina Fathi, designed as a static site for GitHub Pages.

## Publish on GitHub Pages

1. Create a **public** repository named exactly `SinaFathi84.github.io`.
2. Upload all files and folders from this project to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub finishes deployment, visit <https://sinafathi84.github.io/>.

No installation or build command is needed.

## Edit the website

- Main content: `index.html`
- Colors and layout: `assets/styles.css`
- Theme and reveal effects: `assets/script.js`
- Profile image: `assets/sina-fathi.png`
- Contact button and public profile links: `index.html`

## Before publishing

Review dates, research descriptions, authorship status, and contact links before each major update. The full CV is intentionally not included in the public repository.
